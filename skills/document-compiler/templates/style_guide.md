# 教材排版风格指南

## 术语规范

### 中英文混排
- 中英文之间插入空格：`使用 Python 编程` ✅  `使用Python编程` ❌
- 英文专有名词首字母大写：`JavaScript`、`GitHub`、`React`
- 缩写首次出现时标注全称：`API (Application Programming Interface)`

### 代码规范
- 行内代码用反引号包裹：`print("hello")`
- 代码块标注语言：```python
- 变量名用小写蛇形：`user_name`（Python）；驼峰：`userName`（JavaScript）

### 数学公式
- 行内公式：`$E = mc^2$`
- 独立公式块：`$$f(x) = \int_{-\infty}^{\infty} e^{-x^2} dx$$`

## 章节结构规范

每章统一使用以下层级：

```
## 第X章: [标题]
### 本章目标
### 关键概念
### 详细讲解
  #### [小节标题]
### 示例
### 本章小结
### 进阶思考
```

## 练习题规范

```
## 练习题：[章节名称]

### 一、选择题（2题）
### 二、填空题（1题）
### 三、简答题（1题）
### 四、实践题（1题）

---

## 参考答案与解析
```

## 排版细节

- 列表项用 `-` 不用 `*`
- 表格用标准 Markdown 表格语法
- 重要概念首次出现时加粗：**重要概念**
- 每章控制在 2000-3000 字
- 练习题 5 题为宜，每套约 500-800 字
